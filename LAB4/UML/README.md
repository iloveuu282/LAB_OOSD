# UML Bài 4

Mở EShopping_UML.drawio bằng app.diagrams.net qua File → Open from → Device. Có 16 trang mô hình. Các PNG là bản xem trước được tạo từ cùng dữ liệu; bố trí đường nối trong draw.io có thể khác nhẹ do bộ định tuyến của ứng dụng.

Tên mô hình khớp với code. Sequence có các nhánh điều kiện và ghi chú lỗi; mỗi trang tối đa 5 lifeline.
